# Payal AI Automation

Schedules two AI-generated images and one original AI-generated portrait video daily for an authorized Facebook Page. The video is a 5-second MP4 generated by Pollinations' Gemini Omni Flash model, not assembled from still photos. A separate job checks recent Page comments every 30 minutes and replies once per comment. The daily job uses recent post engagement to guide new creative themes and records scheduled slots to avoid duplicate runs.

## Setup

Install Python 3.12 and FFmpeg, then install the dependencies:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Set the environment variables from `.env.example` locally, then run either job:

```powershell
python publish_daily_content.py
python reply_to_comments.py
```

The posting job schedules the images for 07:00 and 13:10 and the video for 17:00 in `Asia/Kolkata`. GitHub Actions runs it daily at 05:45 India time and checks comments every 30 minutes. Dispatching the daily workflow manually also schedules posts; it does not publish them immediately.

## GitHub Actions Secrets

Add these under **Settings > Secrets and variables > Actions**:

- `FB_PAGE_ID`
- `FB_PAGE_ACCESS_TOKEN`
- `POLLINATIONS_API_KEY`
- The Pollinations key needs video-model access and sufficient paid Pollen for `google/gemini-omni-1.1-flash`.
- Optional video settings: `POLLINATIONS_VIDEO_MODEL` and `POLLINATIONS_VIDEO_DURATION` (Gemini Omni supports 3-10 seconds).
- At least one text provider key: `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, or `OPENAI_API_KEY`
- Optional Gemini fallbacks: `GEMINI_API_KEY_2` and `GEMINI_API_KEY_3`

Enable Actions and allow workflows to write repository contents so the jobs can persist duplicate-prevention state. The Page token needs Meta permissions for Page publishing, engagement reads, and comment replies. Meta app review may be required.

Comment text is sent to the configured text provider to draft a reply. The fallback reply is used if all text providers fail.

## Safety

Use only a Page you administer and content you are authorized to publish. Test with a non-production Page before enabling real credentials. Never commit `.env`, API keys, Page tokens, app secrets, or private media.
